# LagFactory (NeoForge 1.21.1)

**LagFactory** is a large-scale modpack built for Minecraft 1.21.1 using NeoForge.  
It combines high-performance optimization with expansive content — focusing on *technology, magic, exploration, visuals,* and *quality-of-life* improvements.  
The goal: to push Minecraft’s limits while remaining surprisingly stable and performant.

---

## 📦 Overview

LagFactory blends the best of multiple mod categories to create a rich, immersive experience.  
Players can automate massive factories, craft powerful spells, explore vast custom worlds, and build with hundreds of new blocks — all in one cohesive pack.

---

## ⚙️ Key Features

### 🛠 Technology & Automation
- **Create** and a full suite of add-ons (e.g. Create: Railways, Slice & Dice, Enchantment Industry)
- **Applied Energistics 2** + wireless terminals and Rechiseled AE2 integration
- **Iron Furnaces**, **Colossal Chests**, and other scalable storage systems

### ✨ Magic & RPG Systems
- **Ars Nouveau** and expansions for custom spellcasting
- **Iron’s Spellbooks** for traditional RPG-style combat magic
- **Health Enchantment** and **Phyton’s Hearts** for enhanced survival systems

### 🌍 World Generation & Exploration
- **Terralith**, **Biomes O’ Plenty**, **Nullscape**, **Incendium**, and **Structory** for a complete world overhaul
- **Oh The Biomes We’ve Gone** and **Oh The Trees You’ll Grow** for biome variety
- Extensive building mod support via **Macaw’s**, **Rechiseled**, **Chipped**, **Adorn**, and more

### 💻 Visuals & Performance
- **Sodium + Iris** for high FPS with shader support on NeoForge
- **ModernFix**, **FerriteCore**, **ImmediatelyFast**, **Lithium**, **Entity Culling**, **Dynamic FPS**, **GPU Booster**
- **Distant Horizons** for extended render distance
- Enhanced visuals via **Continuity**, **Fusion (CTM)**, and **Entity Model Features**

### 🎮 Quality of Life Enhancements
- **Waystones**, **Traveler’s Backpack**, **JourneyMap**, **Nature’s Compass**
- **Better Combat**, **First-Person Model**, **Not Enough Animations**
- **BetterF3**, **Jade**, **Chat Heads**, **Inventory Profiles Next**, **Appleskin**, **Controlling**
- **Simple Voice Chat** for multiplayer integration

---

## 🧠 Performance

Despite its size, LagFactory is designed with optimization in mind.  
The included suite of performance mods allows the pack to remain smooth even with extended render distances and detailed shaders.  
That said, a modern system is strongly recommended.

### Recommended Specifications
| Component | Recommended |
|------------|--------------|
| **CPU** | Ryzen 7 / i7 (or better) |
| **GPU** | RTX 3070 / RX 6800 XT (or better) |
| **RAM** | 8–12 GB allocated |
| **Storage** | SSD recommended |

## 🗺️ Gameplay Style

LagFactory supports all playstyles:
- **Engineers** can automate with Create and AE2.
- **Builders** get hundreds of decorative options.
- **Explorers** can roam endlessly through custom dimensions and biomes.
- **Mages** can master complex spell systems.

It’s designed as a “sandbox of everything” — complex, beautiful, and deeply moddable.

1. Install [NeoForge](https://neoforged.net/).  
2. Download the LagFactory `.zip` or import it via [Modrinth App](https://modrinth.com/app).  
3. Allocate sufficient memory (at least 8 GB).  
4. Launch and enjoy the chaos.
